# Смена Миланы

Игра-тренажёр для будущей акушерки: смены с вопросами, «Правда или миф», «Пульс малыша», копилка из 130 фактов, уровни, значки и подарки.

Сайт: https://valiantdemon2608.github.io/smena-milany/

Прогресс сохраняется в облако (Supabase) автоматически, без входа. Статистика для Димы: dima.html.
